# Dataset Factory

面向 LoRA 训练数据集生产的**打标流水线工具**：用 AI 把切好、归好类的图片 / 视频素材打成能直接送训练的描述（caption），并最终整理成目标模型要的格式。

!!! note "开发状态"
    早期开发中。一期聚焦「AI 打标能力」——发图 → 模型出描述 → 多轮迭代改写。本文档为最小骨架，内容随功能完善逐步补充。

## 模块概览

- **llm**：能力层，全项目唯一与模型端点通信的模块（OpenAI 兼容客户端）。
- **prompts / skills / sessions**：数据域（提示词库 / Skill 包 / 会话持久化）。
- **labeling**：打标编排引擎（组装一轮打标）。
- **cli / api**：入口层（命令行 `dsf` / HTTP），只做翻译、不含业务逻辑。

代码级接口详见 [API 参考](api.md)。
